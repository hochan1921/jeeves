# jeeves

ひとりに、ひとりの執事。相談の相手になり、やりたいことを覚えておく。

やることは 2 つだけ。**`data/tasks.md` にやることを書く**、**ブラウザでダッシュボードを眺める**。
執事（Claude Code）はダッシュボードを読んで、次の一手を先に出す。
話しかければ、相談でも雑談でも相手になり、話したことを覚えておく。ダッシュボードを保つのは、その振る舞いのひとつ。

## 思想

このリポジトリは **フレーム** と **ユーザー情報** に分かれている。

|                  | 中身                                           | git            |
| ---------------- | ---------------------------------------------- | -------------- |
| **フレーム**     | 画面・雛形・執事への指示。誰にとっても同じもの | 管理する       |
| **ユーザー情報** | あなたのダッシュボード。`data/` の下だけ       | **管理しない** |

だから:

- **clone すれば、誰でも同じ執事を自分のダッシュボードで迎えられる。** 他人のダッシュボードが混ざることはない。
- **あなたのタスクが git に載ることはない。** 公開リポジトリでも中身は手元にとどまる。
- **フレームの更新は pull で受け取れる。** ダッシュボードは 1 文字も動かない。

守るのは 1 行の約束だけ ——「ユーザーの生成物は `data/` の下にしか置かない」。

## 構成

```
jeeves/
├── README.md            フレーム │ これ
├── CLAUDE.md            フレーム │ 執事への約束（仕組み）
├── PERSONA.md           フレーム │ 執事の人格（振る舞い）
├── index.html           フレーム │ ダッシュボード（1 ファイル・依存ゼロ）
├── study.html           フレーム │ 教養ページ。映画・ゲーム・本の棚もこれで映す（同じく 1 ファイル・依存ゼロ）
├── news.html            フレーム │ ニュースページ（同じく 1 ファイル・依存ゼロ）
├── server.py            フレーム │ 画面を出す。data/*.md への書き戻しを受け、深堀りを押されたら執事を呼ぶ
├── template/            フレーム │ data/ の雛形。ここを clone 者に配る
│   ├── tasks.md
│   ├── memory.md
│   ├── notes.md
│   ├── talk.md
│   └── secretary.md
├── .claude/
│   ├── launch.json      フレーム │ 画面の起動設定
│   └── skills/
│       ├── news/        フレーム │ ニュースを書き換える手順（/news）
│       └── deepdive/    フレーム │ ニュースを深堀りする手順（/deepdive）
└── data/               ★ユーザー │ git 管理外。あなたのものだけが入る
    ├── tasks.md         あなたのダッシュボード
    ├── memory.md        執事が覚えていること
    ├── notes.md         あなたの記録（1日1行）
    ├── talk.md          執事と話したこと（執事が書く）
    ├── secretary.md     画面に立つ秘書。絵の場所とセリフ
    ├── secretary.png    その絵。名前は自由で、secretary.md から指す
    ├── study/           教養の中身（科目ごとにファイルかフォルダ）
    ├── 映画.md 映画/     映画の棚。表紙と 1 作 1 ファイル
    ├── ゲーム.md ゲーム/ ゲームの棚。同じ形
    ├── 本.md 本/         本の棚。同じ形
    ├── news/            ニュース（1 種類 1 ファイル。毎朝、執事が書き換える）
    └── 深堀り.md        深堀りしたニュースの解説（ニュースページの一番左のタブ）
```

`template/` と `data/` は**同じ形**をしている。雛形が増えたら `data/` の同じ場所に置かれる。
`study/` と `news/` と棚と秘書の絵は雛形を持たない（中身が人それぞれなので）。

## はじめかた

```bash
git clone <このリポジトリ> jeeves && cd jeeves
mkdir -p data && cp -rn template/. data/
```

`cp -rn` は **上書きしない**。あとで pull して雛形が増えたときも、同じ行をもう一度叩けば
足りないファイルだけが埋まる。既存のダッシュボードは無傷。

画面を出す:

```bash
python3 server.py
```

ブラウザで **http://localhost:8765** 。Claude Code からは `.claude/launch.json` の `board` でも起動できる。
同じ Wi-Fi のスマホからは `http://<このマシンのアドレス>:8765` で見えるし、そこからも書き換えられる。
**同じ回線にいる人は誰でも書き換えられる。** 信用できる回線でだけ立てる。

## ダッシュボードの書き方

`data/tasks.md` の表がすべて。Markdown の表なので、エディタでも執事への一言でも書き換えられる。

| ID  | タスク           | 領域 | なぜやる                   | 期限       | 状態 |
| --- | ---------------- | ---- | -------------------------- | ---------- | ---- |
| 1   | 歯医者を予約する | 健康 | 痛くなってからでは高くつく | 2026-10-01 | todo |

- **状態** — `todo` / `doing` / `done` / `drop`
- **領域** — 健康 / 仕事 / 学び / 人 / お金 / 遊び
- **なぜやる** — 空欄にしない。ここが埋まらないタスクは、たいてい要らないタスク。
- **期限** — `毎日` `毎週金` のような繰り返しでも、`2026-10-01` のような日付でもいい。
  日付が過ぎたものは画面で赤くなる。

終わったら **行を消して、完了ログに 1 行**。表は「これからやること」だけに保つ。
消した記録はログに残るので、増えつづけるのはログのほうだけになる。

## 画面

`index.html` は **`data/` を映す**。写しは持たない。

- 状態ごとの列（これから / 進行中 / 完了 / 見送り）。空でも 4 つ並ぶ。落とし先が動かないように
- 「なぜやる」をカードの真ん中に置く
- 期限切れは赤
- 盤の下に **見つけたもの**（`data/notes.md`）。無ければ何も出ない
- 盤の上に **秘書**（`data/secretary.md`）。開くたびに一言。無ければ何も出ない（下の「秘書」）
- **5 秒ごとに自動追従。** リロードは要らない。執事が `data/` を書き換えれば画面が変わる
- 領域ごとの色分け、ライト / ダーク自動、スマホは 1 列
- 左のメニューで **ダッシュボード / 教養 / 映画 / ゲーム / 本 / ニュース** を行き来する。どのページも同じメニューを持ち、スマホでは上に寝る（下の「教養」「ニュース」）

### 画面から直す

- **文字をクリックすればその場で直せる。** タスク・領域・なぜやる・期限。Enter で確定、Esc で取り消し
  （クリックするまでは書ける状態にしない。押したまま動かせば、そこがカードの掴みどころになる）
- **状態はその場で選び直せる。** `todo` / `doing` / `done` / `drop` から直接。順に回す必要はない
- **カードを列へドラッグしても変わる。** 掴めるのはカードの全面（触る端末では選ぶほうで）
- **「＋ 行を足す」** で 1 行増える。ID は自動
- **カード右上の × で行を消す。** 戻せないので、消す前に一度だけ聞く
- 直した瞬間に `data/tasks.md` へ書き戻す。画面には何も溜めない

完了ログへの転記・並び替えは**入れていない**。執事に言えば済む。

書き戻す直前に、読んだときと中身が変わっていないかを確かめる。
変わっていれば**書かずに読み直す**（執事が同時に書いた場合）。だから台帳は 1 つのまま。

## 秘書

ダッシュボードの上に、ひとり立っている。開くたびに一言。絵とセリフは `data/secretary.md`。

- 絵は `![](secretary.png)` の行。`data/` に置いた画像のファイル名を指す。無ければ言葉だけが出る
- セリフは `## 朝` `## 昼` `## 夜` `## いつでも` の下の `- ` の行。開くたびにどれか一行、同じ行は続けて出ない
- 朝は 5 時から、昼は 11 時から、夜は 17 時から。「いつでも」はどの時間帯にも混ざる
- 先頭の `# 名前` が名前

名前も口調もこのファイルで決まる。フレームは何も知らない。
5 秒ごとの追従では変わらない。変えるのはリロードだけ。

機能が増えると、それに触れるセリフが雛形に足される。手元の `data/secretary.md` には `cp -rn` では入らないので、欲しい行だけ写す。

## 記録

`data/notes.md` は、ダッシュボードで「調べる」と決めたことの置き場所。1 日 1 行だけ。

```
## 9/7 の週

- 09-10 (木) ◯◯坂の名前 → 江戸期にここに屋敷があった武家の名字

つながり: この土地は江戸初期に人が入った
```

`## 見出し` が区切り、`- ` が 1 行、`つながり:` が週のまとめ。画面はこの 3 つだけを拾う。
1 行では雑学のままでも、週で並べると時代や土地のつながりが出る。**そこが読む価値のある場所。**

## 教養

`study.html` は、科目ごとに調べたことを読むページ。左のメニューの **教養** から入る。

中身は `data/study/` の下。左ペインには、ここにある `.md` とフォルダがそのまま並ぶ。
科目名は画面のコードに持たない。足すのも消すのもファイル 1 つで、執事に「美術を足して」と言っても済む。

- **ふつうの科目は `<科目>.md` 1 枚。**
- **項目が増えていく科目は `<科目>/` に 1 項目 1 ファイル。** 本数が増えても、1 ページの長さは変わらない。
  `<科目>.md` はその科目の表紙で、ねらいと書き方の型を置く。執事は新しい項目を書く前にここを読む

```
data/study/
├── 歴史.md
├── 仏教.md             表紙。ねらいと型
└── 仏教/
    └── 禅.md            1 項目 1 ファイル
```

書き方は Markdown。画面が拾うのは **見出し（`#`〜`####`）・段落・箇条書き（`- `）・表・区切り線（`---`）・リンク（`[文字](URL)`）・太字（`**`）** だけ。
先頭の `# 題` がページの題になる。無ければファイル名。`[インフェルノ](#映画/インフェルノ)` のように書けば、別のページへ飛べる。

- **読むだけの画面。** 書くのは執事とエディタ。画面からの書き込み・検索は入れていない。フォルダの入れ子は 1 段まで
- **5 秒ごとに自動追従。** 開いたまま、執事が書き足したものが出る
- `study.html#映画/インフェルノ` で直接開ける。スマホでは左ペインが上に横並びになる
- **雛形は置かない。** 科目も型も人それぞれで、`template/` に置けば、消しても `cp -rn` で戻ってくる。型は各自の表紙に書く

日々の 1 行は `notes.md`（時間の軸）。育てたいものだけ科目ページへ（科目の軸）。

### 映画・ゲーム・本

見たもの・遊んだもの・読んだものは、教養から出して棚に置く。左のメニューの **映画** **ゲーム** **本** から入る。
画面は教養と同じ `study.html` で、`study.html?d=映画` のように棚を指して開く。

```
data/
├── 映画.md              表紙。ねらいと型
└── 映画/
    └── インフェルノ.md     1 作 1 ファイル
```

- 書き方も型の置き方も教養と同じ。執事は新しい作品を書く前に表紙を読む
- 棚と教養のあいだも `[インフェルノ](#映画/インフェルノ)` `[古事記](#古事記)` で飛べる。先頭が棚の名前なら棚へ、ほかは教養へ
- 棚の名前（映画・ゲーム・本）は画面のコードが持つ。足すときは `study.html` と 3 枚の左メニューに 1 つずつ

## ニュース

`news.html` は、種類ごとのニュースをタブで切り替えて読むページ。左のメニューの **ニュース** から入る。

中身は `data/news/` の下に 1 種類 1 ファイル。タブには、ここにある `.md` がそのまま並ぶ。
種類の名前は画面のコードに持たない。**足すのはファイル 1 枚。** 執事に「半導体のニュースも足して」と言っても済む。

```
data/news/
├── AI.md
└── J-REIT.md
```

1 枚の形はこう。`---` より上が **ねらい**（何を拾い、何を拾わないか）で、書くのはあなた。
下は執事が毎朝書き換える。

```
# J-REIT

東証REIT指数の大きな動きとその理由、各投資法人の物件の取得・売却、増資、決算。
株価だけのページや投資信託の宣伝は拾わない。

---

## 2026-10-01 (木)

- **見出し** — 何が起きたかを一文。[媒体名](https://…)
```

- **新しい日が上。** 1 日 3〜5 行、出典のリンクつき。7 日より古い日は消える
- 探しても何も無い日は「目立った動きなし」の 1 行。ねらいを直せば、次の書き換えから効く
- **書き込むのは「深堀り」を押したときだけ。** それ以外は読むだけ。5 秒ごとに自動追従。`news.html#J-REIT` で直接開ける
- **雛形は置かない。** 種類は人それぞれ（教養と同じ理由）

### 毎朝の書き換え

手順は `.claude/skills/news/SKILL.md`。Claude Code で `/news` と打てば、いつでも同じことをする。
毎朝の分は Claude デスクトップの定期タスクに任せる。作業フォルダをこのリポジトリにして、1 つ足す。

- いつ：毎朝（たとえば 7:00 なら `0 7 * * *`）
- 指示：news スキル（`/news`）を呼び出して、`data/news/` を今日の分に書き換える

手順書の頭で軽いモデル（`model: sonnet` / `effort: medium`）を指定してある。効くのはスキルとして呼び出したときだけなので、
指示は「ファイルを読め」ではなく「スキルを呼べ」と書く。

アプリが閉じていた朝や、Mac が眠っていた朝は、次に開いたとき・目覚めたときに 1 回だけ走る。1 回ごとに Claude の利用枠を使う。

### 深堀り

各ニュースの横の **深堀り** を押すと、一番左の **深堀り** タブにその話が「作業中...」で入る。
`server.py` が裏で執事（`claude -p`）を呼び、元記事を読んで **要約・解説・取り入れるなら** に書き換える。1〜2 分で、開いたまま変わる。
中身は `data/深堀り.md` に 1 件ずつたまる。新しいものが上。要らなくなった件は、執事に言えば消す。

- 押した分だけ動く。1 件ごとに Claude の利用枠を使う（軽いモデル `sonnet`）
- 裏の執事に許すのは、記事を読むことと `data/深堀り.md` を書き換えることだけ
- `claude` が見つからない場所で `server.py` を立てたときは「作業中...」のまま残る。次に話したとき、執事が書く
- 「取り入れるなら」に案があれば、最後に `**取り入れ**: 未定`。会話で「取り入れますか」と聞かれ、言った分だけ執事がスキルや画面に反映する
- 会話で「このニュースを深堀りして」と頼んでも同じ

## 話したこと

`data/talk.md` は、執事との会話の記録。書くのは執事で、その日のうちに数行。
何の話をしたかと、あなたが何と言ったか。言い換えず、短く。作業の中身は書かない（それは git と完了ログにある）。

```
## 9/7 の週

- 09-08 (火) 異動の打診があった。「今の仕事は、まだ終わっていない気がする」
- 09-11 (金) 断った。「終わらせてから動きたい」

見立て: 迷う時間は長いが、決める理由はいつも「終わらせてから」
```

週の終わりに、執事はその週の行を読み、あなたについて言えることがあれば **見立て** を 1 行足す。
同じ見立てが三度出たら `memory.md` へ移る。話したこと → 見立て → 覚えていること、の順に濃くなる。

執事は、あなたの考える力が育つように話を返す。関連する話題をひとつ添え、覚えておくといいところは **覚えどころ** としてその日の行に添えて、週の終わりにひとつ、あなたの言葉で説明してもらう（振る舞いは `PERSONA.md` の「育てる」）。

用がなくても話していい。雑談は雑談のまま聞き、タスクには変えない（振る舞いは `PERSONA.md`）。
仕事のアカウントと分けたいときは、`CLAUDE_CONFIG_DIR=~/.claude-jeeves claude` のように設定の置き場を分けて起動する。ログインも設定も別になる。

スマホからも話せる。分けた置き場の `settings.json` に次の 2 つを足すと、jeeves を開くたびに、Claude アプリの「Code」にその会話が出る。
置き場を分けていれば、ほかのリポジトリには効かない。

```json
"remoteControlAtStartup": true,
"env": { "CLAUDE_REMOTE_CONTROL_SESSION_NAME_PREFIX": "jeeves" }
```

2 つ目は、一覧に出る名前の頭。足さないと Mac の名前が入る。
つなぎ先は Anthropic のサーバーなので、同じ Wi-Fi でなくても、外から話せる。届くのは、Mac が起きていて、jeeves の会話が開いている間だけ。
つないでいる間は、会話の記録が Anthropic のサーバーにも置かれる。

外から**新しい会話を立てたい**ときは、上の設定では足りない。上の設定やデスクトップアプリの `/remote-control` は、Mac で開いた会話を外に見せるだけ。
外から立てるには、Mac のターミナルで受け口を開けておく。

```bash
claude remote-control --name "jeeves"
```

初回だけ `Enable Remote Control? (y/n)` と聞かれるので `y`。このターミナルが開いている間、別の PC やスマホの claude.ai/code からこの Mac に会話を立てられる。
閉じていると、外からは「このPCをオンラインにしてください」と出る。

**Mac が眠ると切れる。** 蓋を閉じれば、何を設定していても眠る。外から使う間は、電源をつないで蓋を開けたままにする。
システム設定 → バッテリー → オプション の「電源アダプタ接続時にディスプレイがオフのときに自動でスリープさせない」をオンにすれば、画面は消えても本体は起きている。
眠って切れた会話は、別 PC に「切断されました」と出たまま戻らないことがある。そのときは Mac 側で Remote Control を一度切ってつなぎ直す。アドレスが変わるので、外からは一覧から開き直す。

**画面には出ない。server.py も配らない。** 同じ回線の人にも見せない。

## 覚えていること

`data/memory.md` は、執事が会話をまたいで持っておく土台。
ダッシュボードが「これからやること」なら、こちらは **「どういう人か」**。

行き先・物差し・繰り返しつまずくこと・触れなくていいこと、の 4 つだけ。

会話の初めに、執事はダッシュボードと話したことと一緒にここを読む。だから毎回説明し直さなくていい。
同じ話や同じ見立てが三度出たら、執事が一行にして置く。自分で書き足してもいい。

**画面には出ない。server.py も配らない。** 眺めるための盤ではなく、前提として持っておくもの。
長くなるほど前提は薄まるので、増えたら古い行から消す。

Claude Code にも自前の記憶（自動メモリ）があるが、あなたのことはそちらに置かない。
見えないところに、二つ目の台帳を作らないため。

## 執事

読んで動くのは Claude Code。指示は 2 つのファイルに分かれている。

| ファイル     | 中身                                         |
| ------------ | -------------------------------------------- |
| `CLAUDE.md`  | 仕組みの約束。どこに書くか、何を増やさないか |
| `PERSONA.md` | 人格。立ち位置、口調、踏み越えないこと       |

分けてあるのは、**片方だけ書き換えられるようにするため**。
言葉づかいが合わなければ `PERSONA.md` だけ直せばいい。仕組みは動かないまま、態度だけが変わる。
逆に置き場所の約束を変えても、執事の人柄はそのまま残る。

決まった手順は、さらに別に置く。いまは毎朝のニュース `.claude/skills/news/SKILL.md`（`/news`）と、ニュースの深堀り `.claude/skills/deepdive/SKILL.md`（`/deepdive`）。

`claude` を起動すると、執事はまずダッシュボードと、覚えていること・話したことを読む。
「何をしますか」とは聞かず、次の一手をひとつ置く。前の話に続きがあれば、一言だけ触れる。

## 画面を増やすときの約束

これから web 側を充実させていく。そのとき壊してはいけないのは次の 5 つ。

1. **ユーザーの生成物は `data/` の下にだけ置く。** フレームは `data/` の中身を知らなくても動く。
2. **雛形が要るものは `template/` に同じ形で置く。** `cp -rn template/. data/` だけで移行が済む状態を保つ。
3. **`.gitignore` に個別ファイルを足さない。** 足したくなったら、それは `data/` の外に置いたということ。置き場所のほうを直す。
4. **画面は台帳を持たない。** 編集はその場で `data/` のファイルへ書き戻し、競合したら書かない。
   画面が写しを抱えて後から流し込む作りにした瞬間、台帳が 2 つになる。
5. **本人だけのもの（`memory.md` と `talk.md`）は画面に出さない。** `server.py` も配らない。
   会話の画面を足すときも、ここは同じ回線に出さない。

## 手元のデータを移す・残す

`data/` を丸ごとコピーすれば、それが引っ越しでありバックアップ。
クラウド同期のフォルダに置いて `data` をシンボリックリンクにしてもいい ——
フレームは `data/` の実体がどこにあるかを気にしない。
