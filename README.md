# jeeves

ひとりに、ひとりの執事。相談の相手になり、やりたいことを覚えておく。

やることは 2 つだけ。**`data/tasks.md` にやることを書く**、**ブラウザでダッシュボードを眺める**。
執事（Claude Code）はダッシュボードを読んで、次の一手を先に出す。
話しかければ、そのまま相談の相手になる。ダッシュボードを保つのは、その振る舞いのひとつ。

## 思想

このリポジトリは **フレーム** と **ユーザー情報** に分かれている。

|                  | 中身                                           | git            |
| ---------------- | ---------------------------------------------- | -------------- |
| **フレーム**     | 画面・雛形・執事への指示。誰にとっても同じもの | 管理する       |
| **ユーザー情報** | あなたのダッシュボード。`data/` の下だけ       | **管理しない** |

だから:

- **clone すれば、誰でも同じ執事を自分のダッシュボードで迎えられる。** 他人のダッシュボードが混ざることはない。
- **あなたのタスクが git に載ることはない。** 公開リポジトリでも中身は手元にとどまる。
- **フレームの更新は pull で受け取れる。** ダッシュボードは 1 文字も動かない。

守るのは 1 行の約束だけ ——「ユーザーの生成物は `data/` の下にしか置かない」。

## 構成

```
jeeves/
├── README.md            フレーム │ これ
├── CLAUDE.md            フレーム │ 執事への約束（仕組み）
├── PERSONA.md           フレーム │ 執事の人格（振る舞い）
├── index.html           フレーム │ ダッシュボード（1 ファイル・依存ゼロ）
├── study.html           フレーム │ 勉強ページ（同じく 1 ファイル・依存ゼロ）
├── server.py            フレーム │ 画面を出す。data/*.md への書き戻しだけ受ける
├── template/            フレーム │ data/ の雛形。ここを clone 者に配る
│   ├── tasks.md
│   ├── memory.md
│   └── notes.md
├── .claude/
│   └── launch.json      フレーム │ 画面の起動設定
└── data/               ★ユーザー │ git 管理外。あなたのものだけが入る
    ├── tasks.md         あなたのダッシュボード
    ├── memory.md        執事が覚えていること
    ├── notes.md         あなたの記録（1日1行）
    └── study/           勉強の中身（科目ごとにファイルかフォルダ）
```

`template/` と `data/` は**同じ形**をしている。雛形が増えたら `data/` の同じ場所に置かれる。
`study/` だけは雛形を持たない（中身が人それぞれなので）。

## はじめかた

```bash
git clone <このリポジトリ> jeeves && cd jeeves
mkdir -p data && cp -rn template/. data/
```

`cp -rn` は **上書きしない**。あとで pull して雛形が増えたときも、同じ行をもう一度叩けば
足りないファイルだけが埋まる。既存のダッシュボードは無傷。

画面を出す:

```bash
python3 server.py
```

ブラウザで **http://localhost:8765** 。Claude Code からは `.claude/launch.json` の `board` でも起動できる。
同じ Wi-Fi のスマホからは `http://<このマシンのアドレス>:8765` で見えるし、そこからも書き換えられる。
**同じ回線にいる人は誰でも書き換えられる。** 信用できる回線でだけ立てる。

## ダッシュボードの書き方

`data/tasks.md` の表がすべて。Markdown の表なので、エディタでも執事への一言でも書き換えられる。

| ID  | タスク           | 領域 | なぜやる                   | 期限       | 状態 |
| --- | ---------------- | ---- | -------------------------- | ---------- | ---- |
| 1   | 歯医者を予約する | 健康 | 痛くなってからでは高くつく | 2026-10-01 | todo |

- **状態** — `todo` / `doing` / `done` / `drop`
- **領域** — 健康 / 仕事 / 学び / 人 / お金 / 遊び
- **なぜやる** — 空欄にしない。ここが埋まらないタスクは、たいてい要らないタスク。
- **期限** — `毎日` `毎週金` のような繰り返しでも、`2026-10-01` のような日付でもいい。
  日付が過ぎたものは画面で赤くなる。

終わったら **行を消して、完了ログに 1 行**。表は「これからやること」だけに保つ。
消した記録はログに残るので、増えつづけるのはログのほうだけになる。

## 画面

`index.html` は **`data/` を映す**。写しは持たない。

- 状態ごとの列（これから / 進行中 / 完了 / 見送り）。空でも 4 つ並ぶ。落とし先が動かないように
- 「なぜやる」をカードの真ん中に置く
- 期限切れは赤
- 盤の下に **見つけたもの**（`data/notes.md`）。無ければ何も出ない
- **5 秒ごとに自動追従。** リロードは要らない。執事が `data/` を書き換えれば画面が変わる
- 領域ごとの色分け、ライト / ダーク自動、スマホは 1 列
- ヘッダー右の **勉強 →** で勉強ページへ（下の「勉強」）

### 画面から直す

- **文字をクリックすればその場で直せる。** タスク・領域・なぜやる・期限。Enter で確定、Esc で取り消し
  （クリックするまでは書ける状態にしない。押したまま動かせば、そこがカードの掴みどころになる）
- **状態はその場で選び直せる。** `todo` / `doing` / `done` / `drop` から直接。順に回す必要はない
- **カードを列へドラッグしても変わる。** 掴めるのはカードの全面（触る端末では選ぶほうで）
- **「＋ 行を足す」** で 1 行増える。ID は自動
- **カード右上の × で行を消す。** 戻せないので、消す前に一度だけ聞く
- 直した瞬間に `data/tasks.md` へ書き戻す。画面には何も溜めない

完了ログへの転記・並び替えは**入れていない**。執事に言えば済む。

書き戻す直前に、読んだときと中身が変わっていないかを確かめる。
変わっていれば**書かずに読み直す**（執事が同時に書いた場合）。だから台帳は 1 つのまま。

## 記録

`data/notes.md` は、ダッシュボードで「調べる」と決めたことの置き場所。1 日 1 行だけ。

```
## 9/7 の週

- 09-10 (木) ◯◯坂の名前 → 江戸期にここに屋敷があった武家の名字

つながり: この土地は江戸初期に人が入った
```

`## 見出し` が区切り、`- ` が 1 行、`つながり:` が週のまとめ。画面はこの 3 つだけを拾う。
1 行では雑学のままでも、週で並べると時代や土地のつながりが出る。**そこが読む価値のある場所。**

## 勉強

`study.html` は、科目ごとに調べたことを読むページ。ダッシュボードのヘッダーの **勉強 →** から入る。

中身は `data/study/` の下。左ペインには、ここにある `.md` とフォルダがそのまま並ぶ。
科目名は画面のコードに持たない。足すのも消すのもファイル 1 つで、執事に「美術を足して」と言っても済む。

- **ふつうの科目は `<科目>.md` 1 枚。**
- **項目が増えていく科目は `<科目>/` に 1 項目 1 ファイル。** 本数が増えても、1 ページの長さは変わらない。
  `<科目>.md` はその科目の表紙で、ねらいと書き方の型を置く。執事は新しい項目を書く前にここを読む

```
data/study/
├── 歴史.md
├── 映画.md             表紙。ねらいと型
└── 映画/
    └── インフェルノ.md    1 作 1 ファイル
```

書き方は Markdown。画面が拾うのは **見出し（`#`〜`####`）・段落・箇条書き（`- `）・表・区切り線（`---`）・リンク（`[文字](URL)`）・太字（`**`）** だけ。
先頭の `# 題` がページの題になる。無ければファイル名。`[インフェルノ](#映画/インフェルノ)` のように書けば、別のページへ飛べる。

- **読むだけの画面。** 書くのは執事とエディタ。画面からの書き込み・検索は入れていない。フォルダの入れ子は 1 段まで
- **5 秒ごとに自動追従。** 開いたまま、執事が書き足したものが出る
- `study.html#映画/インフェルノ` で直接開ける。スマホでは左ペインが上に横並びになる
- **雛形は置かない。** 科目も型も人それぞれで、`template/` に置けば、消しても `cp -rn` で戻ってくる。型は各自の表紙に書く

日々の 1 行は `notes.md`（時間の軸）。育てたいものだけ科目ページへ（科目の軸）。

## 覚えていること

`data/memory.md` は、執事が会話をまたいで持っておく土台。
ダッシュボードが「これからやること」なら、こちらは **「どういう人か」**。

行き先・物差し・繰り返しつまずくこと・触れなくていいこと、の 4 つだけ。

会話の初めに、執事はダッシュボードと一緒にここを読む。だから毎回説明し直さなくていい。
同じ話が三度出たら、執事が一行にして置く。自分で書き足してもいい。

**画面には出ない。** 眺めるための盤ではなく、前提として持っておくもの。
長くなるほど前提は薄まるので、増えたら古い行から消す。

## 執事

読んで動くのは Claude Code。指示は 2 つのファイルに分かれている。

| ファイル     | 中身                                         |
| ------------ | -------------------------------------------- |
| `CLAUDE.md`  | 仕組みの約束。どこに書くか、何を増やさないか |
| `PERSONA.md` | 人格。立ち位置、口調、踏み越えないこと       |

分けてあるのは、**片方だけ書き換えられるようにするため**。
言葉づかいが合わなければ `PERSONA.md` だけ直せばいい。仕組みは動かないまま、態度だけが変わる。
逆に置き場所の約束を変えても、執事の人柄はそのまま残る。

`claude` を起動すると、執事はまず `data/tasks.md` を読む。
「何をしますか」とは聞かず、次の一手をひとつ置く。

## 画面を増やすときの約束

これから web 側を充実させていく。そのとき壊してはいけないのは次の 4 つ。

1. **ユーザーの生成物は `data/` の下にだけ置く。** フレームは `data/` の中身を知らなくても動く。
2. **雛形が要るものは `template/` に同じ形で置く。** `cp -rn template/. data/` だけで移行が済む状態を保つ。
3. **`.gitignore` に個別ファイルを足さない。** 足したくなったら、それは `data/` の外に置いたということ。置き場所のほうを直す。
4. **画面は台帳を持たない。** 編集はその場で `data/` のファイルへ書き戻し、競合したら書かない。
   画面が写しを抱えて後から流し込む作りにした瞬間、台帳が 2 つになる。

## 手元のデータを移す・残す

`data/` を丸ごとコピーすれば、それが引っ越しでありバックアップ。
クラウド同期のフォルダに置いて `data` をシンボリックリンクにしてもいい ——
フレームは `data/` の実体がどこにあるかを気にしない。
