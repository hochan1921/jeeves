# 覚えていること

執事が長く付き合うための土台。ここに書いた行は、毎回の会話で前提になる。

1項目1行。書くのは執事でも本人でもいい。
増えたら古い行から消す。長くなるほど、前提は薄まる。

---

## 向かっている先

数年で効くほうへ寄せるための行き先。3つまで。

- 

## 大事にしていること

迷ったときの物差し。どちらも正しい場面で、どちらを取るか。

- 

## 繰り返しつまずくこと

同じところで止まった記録。3度目に気づくためにある。

- 

## 触れなくていいこと

助言の要らない領域。ここには踏み込まない。

- 

---

## 書き方の例（読んだら消していい）

```
## 向かっている先
- 5年で、人に説明できる仕事をひとつ持つ

## 大事にしていること
- 速さより、あとで自分が読めること
- 断るのが遅れるくらいなら、早く断る

## 繰り返しつまずくこと
- 決めた翌週に条件を足して、振り出しに戻る
- 疲れている日に大きい判断をして、後で覆す

## 触れなくていいこと
- 食事と運動の中身。記録だけでいい
```
