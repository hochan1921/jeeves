# 見つけたもの

管理票で「調べる」と決めたことの記録。1日1行。
書き方は「見たもの → わかったこと」。それ以上は書かない。
週に一度、その週の行をまとめて読み、共通点があれば「つながり:」に1行。

---

## 書き方の例（読んだら消していい）

- 09-01 (火) ◯◯坂の名前 → 江戸期にここに屋敷があった武家の名字が残ったもの
- 09-02 (水) 商店街の「〜屋」の屋号 → 商人が苗字を名乗れなかった時代の代わり
- 09-03 (木) 近所の神社の由緒書き → 勧請元が九州。江戸初期に移された
- 09-04 (金) 隣の駅名 → 昭和の埋立てでできた地名。江戸の地図では海

つながり: この土地は江戸初期に人が入り、海側は昭和にできた。境目はあの坂
